# 先自由写作，再进入语言学习

规则来自本机 CognosOS Launcher 实际启动的 `/Users/john/Documents/Diarybot` 项目：`frontend/src/lib/breakthrough.ts` 中 mental_dump 阶段采用 300 秒压力窗口、8 秒停笔上限、4 秒提醒窗口；`frontend/src/App.tsx` 处理渐淡、中文输入法和清空。这里只迁入这段自由写作体验，不启动或改动 CognosOS，也不复制它的后续反思流程。

在“新的想法”中点击“先自由写 5 分钟”，立即开始独立的写作计时。先不组织内容，不判断语法。前五分钟停笔满八秒，本轮编辑区和暂存文字清空；最后四秒渐淡并提示继续。失败后可以重新开始。旧的粘贴原文、已完成写作及语言练习不受影响。“放弃并清空本轮”只清空本轮。

中文输入法组合输入期间保护计时；方向键、选中文字和不改变内容的输入事件不重置停笔时限。切换到后台、刷新或电脑休眠不会重置五分钟计时。恢复时按截止时间先后判定，不能因为后台挂起超过五分钟就将已经超时的写作判为完成。若停笔与五分钟截止恰好相同，以完成处理。

写满五分钟解除停笔清空限制，可继续书写。点击“保留原文，进入语言学习”后，原文先写入本机 SQLite 的独立 `freewrites` 表，再带到内容入口；选择英语/日语、点击“整理我的想法”，才会把这份内容发给 Gemini。确认摘要、结构和逐句表达后沿用原有的填空、Jev 检查和 Gemini 整句反馈。完成五分钟只表示写作过程结束，不作学习能力判断。

未完成写作使用当前标签页的 sessionStorage 暂存；刷新恢复原计时，关闭标签页会丢失未交接的内容。交接成功后清除临时副本，原文独立保存，即使后续 Gemini 请求失败或候选改变也保留。生成前可编辑用于学习的副本。若入口原本有文字，临时保存一份原输入，可点击“恢复写作前的输入”切回。

实现文件：`studio/web/freewrite-state.mjs` 管理截止时间与状态；`freewrite.js` 接入编辑器和 IME；`studio/server/freewrites.mjs` 保存原文。`POST /api/sentence/freewrites` 只接受 `{id, text, started_at, finished_at}`，文本最多20,000字符，沿用本地鉴权与同源策略。相同 ID 与正文重试不重复保存；同 ID 换内容返回409。写作原文不伪装成用户的外语答题记录。
