# 可选视觉支架接口

首版直接显示文本与词块，无需图像。独立视觉能力复用可用的 `imagegen` 技能；精确图表应使用相应绘图工具，不在运行时另造模型服务。

交给视觉工具的请求包含：当前 pack_id、对象 ID、要支持的意义、允许引用的来源、所需媒介、事实边界。工具返回已验证的本地资产、资产版本、类型（原典 / AI 生成 / 精确绘图）、来源定位（未知为 null）与替代文本；不得修改用户产物、学习结论或正式原典。

本版没有任意文件读取或媒体上传接口，也未实现资产显示。需要接图像时必须先扩展受控资产目录、只读路由和 pack 校验，再将已验证资产登记；这是后续扩展接口说明，不是已实现的媒体能力。
