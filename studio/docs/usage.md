# 怎么用 · 完整说明

> 这份说明写于文字部分只接 Gemini 的时候。现在文字、语音陪练和朗读都可以在「服务与 key」里分别换成 DeepSeek 或阿里云百炼（千问）；文中的「Gemini」指你选的文字服务，「Gemini Live」指你选的语音服务。


产品以尽快表达正在思考的话题为目标：先表达母语想法，再借助外语参考与随手可取的提示完成表达。词汇和语法解释服务于当下表达，不要求先背会、不因查看提示扣分；完成一次表达不等于长期掌握。

想先畅所欲言，可以点击“先自由写 5 分钟”：前五分钟停笔八秒，本轮文字消失；写满后解除限制，再点“保留原文，进入语言学习”。原文先在本机单独保存，再由 Gemini 提炼表达；旧材料与练习记录不受影响。规则与恢复方式见 [自由写作](studio/docs/freewrite.md)。

点“新的想法”，粘贴最多 20,000 字符的聊天、写作或想法，选择英语/日语，按需补充想强调的重点。点“整理我的想法”，Gemini 先给出中文摘要、核心逻辑、核心结构、辅助逻辑和辅助结构，再生成相应的外语表达。简单意思可一句，通常两三句，复杂内容可更多；原型每次最多 12 个练习单元。提示词要求不补造原文没有的因果和理由。每句标明作用、衔接关系及原文依据，并备好词汇语法、按意思拆解的短语和分级提示。确认后点“意思与结构对了，开始学习”；有偏差可修改原文或重点，再重新整理。生成时会把这一份原文和重点发送给 Gemini。

确认材料后逐块练习，每一块都是**先学、再默写**：屏幕先显示这一块的中文意思和外语写法，进入每一块时语音讲解自动开始（也可按 ⌘ ] 手动开始，设置里可以关掉自动开始），陪练直接开讲，不用先开口：把这一块切成词组、从第一个起逐个讲意思，全部讲完再讲需要注意的语法点，然后等你提问（也可随时插话）；它不会让你跟读或复述。听完按 ⌘ ↵ 收起外语，凭记忆把它写出来。默写的是刚刚学过的表达，而不是猜一个没见过的词。不想学也可以直接按 ⌘ ↵ 默写，不拦，但这一块会记为未学，之后的整句表达都带着“学过几块”的记录。学过（或已跳过）的块重练时直接进入默写。

默写时 Command / Ctrl + Enter 检查。和参考一字不差就直接进入下一块；其它写法会停在这一块看点评：你写的（有批改就画红笔）、参考写法和说明并排显示，语音陪练自动讲这次点评，聊完再按 Command / Ctrl + Enter 进入下一块，下一块从干净的界面开始。没通过时也会自动讲批改：改了再按是重新检查，不改直接按就按原文进入下一块。整句点评之后同样按 Command / Ctrl + Enter 完成并进入下一句。语音面板里能看到这一句所有的对话记录；让陪练拆词时，它按“前缀、词根、后缀 → 字面意思 → 怎么演变成今天的意思”的固定顺序讲。最后一块完成后进入空白整句试写，由你重新组织句子；整句提交后 Gemini 给反馈和百分制分数，超过 95 分自动进入下一句的短语阶段。整句只在最后一块写完后自动打开，没有“直接写整句”的捷径。旧材料点“先练短语”时由 Gemini 补充一次拆解并保存，已有作品与反馈不覆盖。见 [短语练习](studio/docs/phrases.md) 和 [一句话接口](studio/docs/sentence.md)。

文字提示全自动，界面上没有提示按钮：短语默写和整句试写一开始、框还空着时先给一个开头方向；写着写着停笔 1 秒，就根据已写的内容给一句提示；给过提示后一直没动（10 秒），再自动给关键词（整句里是下一个词）。参考答案和整段续写不会自动露出，真卡住了按 ⌘ [ 仍可逐级要（没有按钮，只剩快捷键）。沿参考写时本地立即算出提示，自由措辞由 Gemini 结合光标上下文判断。每条提示都留在输入框下方的列表里，最新的在最上面，正在念的那条标出来，点一条可以再听；提示会大方地给出关键词（原形），怎么组合、怎么变形留给你自己写；不改写正文。卡在某个词或某句话上时，⌘ ] 叫语音陪练当场讲。提示默认用正在学的语言、非常简单的日常说法，像 mentor 一样说话；也可以在设置里改回中文。提示出来的同时会被念出来：Mac 上用系统语音，在 Microsoft Edge 里优先用微软的 Natural 神经语音（免费，但提示文字会经过微软的服务），陪练说话时不念。两项都可在“更多 → 练习记录与设置”里关掉。系统设置 → 辅助功能 → 朗读内容 → 系统语音 → 管理语音里下载“婷婷（增强）”等高音质中文语音后，会自动优先使用。见 [动态写作帮助](studio/docs/writing-help.md)。

短语阶段中文提示保持可见，Command + [ 逐级给结构、开头和参考答案；看过参考后可直接继续，求助不扣分。界面只保留一个写作区：顶部是语言与句序，中间是当前意思和输入框，下面是一条按需出现的提示或反馈；每写完一块，点评就停在这一块上，并排显示你写的（有批改就带红笔）、参考写法和说明，看完、聊完再往下。检查、整句点评进行时不显示“正在检查”之类的状态文字。进度自动保存，没有单独的“先到这里”；篇章大纲、完整点评和练习记录都在同一个抽屉里按需打开。旧填空数据与接口保留用于兼容，默认入口已替换。Gemini 配置与评分规则见 [Gemini 配置](studio/docs/gemini.md)。

## 旧主题练习（仅本机版）

在首页“练习记录与设置”中打开原来的主题练习，或访问 `http://127.0.0.1:4317/legacy`。

选择 English 或日本語，然后“开始 / 继续”。主画面以一个动态提示区为中心，显示当前问题、词块与已开启的中文意义提示。“给一点提示”每次显示一个已登记词块，“少给提示”按你的点击减少帮助。底部“材料与记录”收纳意义／语言支架设置、参考、变式、会话选择与记录。

展开“材料与记录 → 保存我的表达”，“开始一次表达”登记支架起点和表达中状态；“我说完了”结束说话标记。草稿自动保存，保存表达时明确来源和是否经本人确认；原始表达、实际转写、AI 建议和模拟回答分开。写下下次入口后“停在这里”；之后可恢复或导出 Markdown。

“材料与记录 → 针对某处求助”将最新求助和最小必要状态发送至 TypeSafe，只在已登记词块里选择。高置信且门控通过才执行；需要新内容或低置信则回到当前 Codex 对话。此功能会调用你的 API，不是离线推理。

语音陪练在网页内：学某一块、默写或整句试写时按 ⌘ ] 开始，和 Gemini Live 直接对话，问词义、两个词的区别、搭配和语法，问明白了再按 ⌘ ] 结束、自己打出来。它不评价发音——收到的是转写而不是原始音频，判断不了读得准不准，也不该在写作练习里占用注意力。试写时陪练知道你要表达的中文意思和你写到哪里，拿不到准备好的参考句；**学某一块时是唯一例外**——那时它要教的就是这一块，所以只看得到这一块的外语写法，作为交换，这次对话锁在这一块的学习里，一开始默写就结束，不会带着答案跟进试写。批改出来时（某一块没通过、通过但有小修改、整句点评有改动），陪练也会自动开讲：拿你写的和批改后的写法作上下文，一处一处讲原来写的是什么、改成了什么、为什么，讲完等你提问；它看不到参考答案。整段对话会记进这次尝试的帮助记录。规则见 [语音陪练](studio/policies/voice-policy.md)。原生 Voice 与 Codex 陪练已停用。
