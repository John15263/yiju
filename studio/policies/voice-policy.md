# 生成台：语音陪练规则

语音陪练在网页内运行，由本地服务连接 Gemini Live 模型（`bidiGenerateContent`）。这份规则说明它能做什么、拿得到什么、以及每次对话怎么留痕。旧版由 Codex 原生 Voice 承担陪练的做法已经停用；`record_support` 与 `voice_transcript` 仍保留，供 CLI 协作时登记对话中给过的帮助。

## 何时可用

学某一块、默写、整句试写和看整句点评时可以开始，且必须是当前活动的一句和当前窗口。窗口切换、换句、暂停或提交时，会话立即结束。会话分四种（`web/voice-mode.js`，服务端和页面共用同一份判断）：学习（learn）、批改讲解（fix：某一块被批改；review：整句的点评），以及试写（write）。**学习和批改讲解会话只属于那一刻**：学习会话在这一块开始默写时结束，不带着答案进入默写；批改讲解在重新检查、进入下一块、回去修改整句时结束。试写会话只在块与块之间跟着走，遇到学习或新的批改也结束，交给对应的会话。同一时刻只有一个会话；新会话开始时如果旧的还没挂断，旧的直接结束、让位给新的，不再以“已有会话”为由拒绝。默认上限 10 分钟（`VOICE_MAX_SECONDS`），到点自动结束。

## 陪练做什么

解释词义和近义词区别、搭配、句型、语法形式；举例说明用法；回答用户当场的疑问。这是写作练习的一部分，目标是让用户自己把这一块写出来，所以不做发音训练，不让他用语音复述或造句，也不替他把整句说出来。

**学某一块时**另有一份提示词：它的任务是在他默写这一块之前，把这一个表达的意思讲清楚。顺序固定：不先念整块、不先解释整块意思，而是把这一块按原文顺序切成词组，从第一个起逐个讲含义和在这里取的义项，全部讲完后再讲需要注意的语法点，说一句“这一块讲完了”就停下来等他提问。只讲意思和结构，**不让他跟读、复述、用语音说一遍或造句，也不问他会不会说**，因为说不说得出来和随后能不能写出来无关。只讲这一块，其它块轮到时再讲；讲完就停下来等他提问，不把整句连起来念——整句是他随后要自己组织的部分。

学习会话接通后由陪练先开口：收到 `setupComplete` 后，服务端代发一个固定的开讲回合（“他刚按下讲解按钮，还没有说话”），模型随即开始讲解。这个回合不是他说的话，不写进转写。试写会话不代发，仍然等他提问。

## 陪练拿得到什么

会话开始时，服务端组装上下文并发送：目标语言、这一句的中文意思、当前小块的中文意思与位置、这一句在整段里的作用和衔接。会话进行中，页面把输入框里的当前草稿作为上下文更新发过去，不要求陪练回应。

试写阶段（短语、整句）**不发送准备好的参考句、短语参考、关键词和句子骨架**。这些是分级支架，由用户显式取用并单独留痕。陪练据中文意思教零件，不替用户念出整句。

**学某一块时是唯一的例外**：这时会发送这一块的中文意思、外语写法和结构提示，因为它的全部任务就是教这一个表达；不发送其它块、整句参考和整句的语法说明。作为交换，该会话被锁在这一块的学习内——一开始默写就结束，绝不带着答案进入默写；学习时也不发送草稿，因为那时还没有输入框。

模型本身会外语，这和网页是否隐藏参考是两件事：陪练说出的任何目标语言内容都算帮助，按下面的方式记录。网页隐藏答案不能撤回对话里已经说过的内容。

## 提示词与传输由服务端拥有

页面只能发送四种消息：麦克风音频、音频结束、文字提问、当前草稿。setup、模型名、system instruction、思考级别一律由服务端构造，页面无法改写，与 REST 通道的规则一致。API key 不进入页面；浏览器连接的是本地服务，由本地服务连接 Google。

## 留痕

`inputAudioTranscription` 与 `outputAudioTranscription` 同时开启，服务端在中继过程中收集双方转写。会话结束时写入一条 `voice_session` 支持事件，含模型、时长、轮数、所属阶段和转写（上限 20,000 字符），级别取当时的 `support_level`。该事件与其它帮助一样进入后续 attempt 的 `support_events` 快照，在练习记录里显示为「含语音陪练 N 分钟」。

学习会话另外累加到那一块的 `learn`（次数与秒数），`voice_session` 事件记下 `stage: learn` 和块序号。离开学习时按**实际发生过什么**结算：一次会话都没有就记 `skipped: true`，不看用户按的是哪个按钮；会话关闭晚于“开始默写”时，关闭时补记并把 `skipped` 改回 false。随后每次 attempt 带上 `learned` 快照（聊过几块、共几块），所以任何一次表达都能回答「这些表达在写之前学过没有」。

没有取得转写时仍然记录会话本身，只是转写为空——用过陪练这件事不因为拿不到文字而消失。

## 不做什么

不打分，不判断"学会了"，不生成掌握百分比。用户关掉对话就结束。**不评价发音、语调或口音**：陪练拿到的是转写文本，不是原始音频，没有判断发音的依据；转写里的怪词按识别错误处理，不当作用户说错。语音差异不单独作为发音或语法错误的证据。不录制或保存原始音频，只保存转写文本。

## 批改讲解

批改一出来，陪练就开讲：它拿到的是屏幕上已有的东西——你写的原文、批改后的写法（Gemini 给的最小改动）、批改说明，整句的还有点评和分数——以及服务端从这两段文字逐词比出来的改动清单（原来写的 → 改成；只加或只删的词带上前后一个词定位，比如 is escape → is to escape）。**准备好的参考答案不给**：没通过的块还要自己改，回去修改整句时也一样。讲解顺序固定：逐条说出原来写的、改成了什么、背后的规则；只差大小写标点的一句带过；写对的一句肯定；说“批改讲完了”后停下来等提问。不让跟读复述，不问懂没懂。

什么时候要讲：某一块检查没通过（有批改说明）；某一块通过了，但批改给了改写，**或者他的写法和参考写法不一样**（比如参考用 and、他写了 or，判定通过也没给改写——2026-09-23 实际遇到，之前的规则漏讲了）；整句点评的建议写法和原文不同。只差大小写、空格、标点不算，撇号算（dont 和 don't 不同）；和参考一字不差的不讲。通过但和参考写法不同的块停在本块看点评，这时单独开一段批改讲解：拿到他写的、参考写法、批改和说明、两处不同的逐词清单，只就不同的词讲清楚差别，写法成立就明确说成立，最后提醒按 Command 回车进入下一块。他按下之后这段讲解结束，下一块的学习会话重新开始，只讲那一块，不再提上一块（2026-09-23 起；之前是把上一块塞进下一块的讲解开头，两段混在一起）。通过后参考写法已经显示在对比卡片上，所以这时交给陪练；还没通过的块仍不给。整句打分超过 95 自动进入下一句的，不单独讲。批改讲解计入用量里的“批改讲解”。

2026-09-23 用真实 key 试过一次整句讲解（三处错误）：先给改动清单之前，它只把批改说明复述了一遍；加上清单并要求“原来写的、改成、规则”三样之后，每一处都讲到了规则（如“deep 是单音节形容词，最高级直接加 est，不用 most”）。

## 词根词缀

他让陪练拆一个词时（任何一种会话都一样），按固定顺序讲：拆开（前缀、词根及其来源语言和本义、后缀）→ 合起来的字面意思 → 怎么演变成今天的意思 → 可以再给一个同根词。来源拿不准就说拿不准，不硬拆、不编词根。2026-09-23 实测：问提示词里举过例的 territory 和没举过例的 incredible，都按这个顺序讲对了（in- 不 + cred 相信 + -ible 能够 → 不能相信的 → 好得不可思议；同根词 credit）。

## 对话记录

换到下一句时语音面板自动收起、清掉上一句留下的状态，下一句第一块开讲时再打开。同一个练习同时开在两个窗口（两个标签页或两个浏览器）时，只有正在用的那个窗口会自动开讲、自动要提示，另一个不动，免得两边各开一段、互相顶掉、重复花钱（2026-09-23 的记录里出现过同一秒开两段语音）。

语音面板按顺序显示这一句的全部对话：已结束的来自练习记录（每段 `voice_session` 的转写），每段前面标“短语 N · 讲解 / 批改讲解 / 陪练”或“整句 · 点评讲解 / 陪练”，最后是进行中的这段。刚结束的一段先留在页面上，等练习记录里出现同一个 `session_id` 再换成记录里的，所以不会重复也不会闪没。刷新页面后历史还在；换到下一句时只显示那一句的对话。往上翻看时不会被新内容拉回底部。

## 自动开始与自动结束

进入某一块的学习、看到有改动的批改时，页面自动开始对应的会话（“更多 → 练习记录与设置”里的“进入每一块时，自动开始语音讲解”，默认开启，记在本浏览器）。刷新页面、没有改动的批改、普通默写和整句试写不会自动开始，仍可按 ⌘ ] 或点按钮。浏览器不允许无手势播放声音时，不开始会话并提示按 ⌘ ]——对着无法播放回答的页面说话只会花钱。

会话里连续 `VOICE_IDLE_SECONDS`（默认 90 秒）没有任何对话——陪练没说话、没识别到用户说话、没有文字提问或草稿变化——就自动结束，防止自动开始的会话在离开时一直计费。麦克风在安静时也在传音频，所以“安静”按说了什么判断，不按有没有音频。

## 花费

页面上的金额按 Google 公布的每分钟价格粗算，是下限。Live 每一轮都会把前面的整段对话（含双方音频）按音频输入价重新计费，轮数越多、会话越长，实际越高于这个数。
